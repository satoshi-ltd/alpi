# Example hotel briefs

This directory holds realistic inputs used to exercise Web Factory manually.

- `boutique/` — compact design-led hotel with limited confirmed media
- `jaime-primero/` — content-rich family resort
- `kivir/` — existing hotel with supplied photography and detailed facts

These examples are not copied into new projects automatically. A real run receives
an immutable `brief.md` plus any supplied media, which bootstrap moves into the
clone's `assets/source/` directory.
