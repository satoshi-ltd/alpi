# Theme passports

Use these as selection guidance. Always confirm allowed values against the cloned
project's `factory/template-spec.json`.

## Essential

For hotels that need a direct, familiar and conversion-led site. Information
hierarchy is compact; rooms, location, benefits and booking are easy to scan.
Choose it when clarity and operational utility matter more than editorial drama.

## Signature

The default and most adaptable system. It combines strong hospitality imagery,
expressive typography and restrained motion without depending on a large content
inventory. It must work for one-room properties and content-rich hotels alike.

## Immersive

For hotels with exceptional visual material and a defensible narrative. It uses
more cinematic composition and motion, so asset quality and storytelling depth
must justify the choice. Do not select it merely to make a site look expensive.

## Decision order

1. Honor an explicit client theme.
2. Otherwise select the best fit from confirmed content, audience and assets.
3. If no informed decision is made, use `signature`.

Theme selection does not authorize custom CSS or new layout variants in a hotel
project. Use the supported makeup and token surface first.
