# Example configs

Each file is a complete `site.json` for a different theme. **To try one, copy
its contents over `../site.json`.** It reskins the whole site — theme, tokens,
nav, active pages — without touching a component.

| File | Theme | Example hotel |
|---|---|---|
| `../site.json` (active) | boutique | Casa del Faro |
| `resort.palmar.json` | resort | Palmar Island Resort |
| `business.meridian.json` | business | Meridian City Hotel |
| `budget.nido.json` | budget | Nido Hostel |

> The example content (`src/content/**`) is shared; for a real hotel the AI
> also fills the project-specific content, not just the config.
