## When to use
When writing a landing page, email subject line, blog post title, ad creative, or any content where the headline will determine whether the rest gets read. Also use when an existing headline is underperforming and alternatives are needed.

## Output format

**Content being headlined** — one sentence on what the piece is about and what it should make the reader do or feel.

**Primary audience** — who reads this. The right headline for a developer is wrong for a VP of Sales.

**Variants** — produce at least six, across different angles:

| # | Headline | Angle | Why it might work |
|---|---|---|---|
| 1 | | Benefit-led | |
| 2 | | Problem-led | |
| 3 | | Curiosity | |
| 4 | | Specificity (number/stat) | |
| 5 | | Social proof or authority | |
| 6 | | Direct/imperative | |

**Recommendation** — which variant to test first and why.

**What to avoid for this piece** — angles that don't fit this context (hype, false urgency, clickbait) with a one-line reason.

## Approach
- The headline is a promise. If the content doesn't deliver what the headline implies, the reader feels deceived. Write the content first, then headline it.
- Specific beats general. "Save 4 hours a week" outperforms "Save time." "17 companies switched in 30 days" outperforms "Companies are switching."
- Register matters more than cleverness. A clever headline in the wrong register (too casual for a legal audience, too formal for a consumer brand) fails even if it's well-written.
- Generate variants before evaluating them. Evaluating while generating causes premature convergence on the first decent idea.
- The best headline is often the most direct one. Clarity converts; cleverness intrigues. Match to intent.
