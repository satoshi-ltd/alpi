alpi design systemOne token file, common/tokens.mjs, feeds both clients: desktop reads it as CSS custom properties (tokens.css, parity-tested), mobile through useTheme(). Geist for text, Geist Mono for labels and numbers, Lucide icons at 1.75 stroke. The brand accent is Continuity amber: deep on light, signal on dark; the alpaca stays black on white.
