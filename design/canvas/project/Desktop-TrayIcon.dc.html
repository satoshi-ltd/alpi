Rules
One ink with binary alpha: the asset is a template the OS tints for the bar, so it reads on a light, a dark and a translucent bar. The facets sit on the pixel grid of each size, the creases are exact 1 px gaps from 32 px, and the marks carry a 1 px knock-out.Priority: needs you (ring), then offline (slash), then unread or an update (dot), then quiet. The icon is set once, and only when the state or the size changed.Windows and Linux pick the size from the display scale when the state changes: moving the app between displays of different scale keeps the old size until the next state change.
