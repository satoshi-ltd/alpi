UI-WORKGROUP.RUN-LIMITS · mobile · desktop · New workgroup
A new workgroup sets how long the hub waits for members and how much a run may spendhost.workgroup.create already takes quorum_timeout_seconds and budget_usd, and the console edits both, but neither client sends them, so every workgroup made from the apps starts with the 10-minute default wait and no spend cap. The proposal adds the two settings to New workgroup on both clients, in plain words, with the defaults preselected; the rest of the form is unchanged.
