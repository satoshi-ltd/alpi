Proposed
Tokens

--dur-1 120 ms · --dur-2 200 ms · --dur-loop 1.4 s · one ease

Reduced motion

one global rule stops every loop and fades

New turn

rises 8 px and fades in, 200 ms, only the newest

Streaming

the newest slice fades in 150 ms; nothing earlier re-animates

Reasoning

collapses to “Thought for Xs” when the answer lands

Phone keyboard

useAnimatedKeyboard moves the composer frame by frame

Why. Motion is the cue that something changed. Today the moments that matter (a new turn, the streaming edge, the keyboard) are static while decorative loops run at six unrelated speeds and ignore the user's reduced-motion setting.

Seen in. Claude and ChatGPT fade only the newest text; Dia's polish is mostly fluid motion; iOS expects the input to ride the keyboard.

Buttons

Tooltips

one Tip, keyboard hint included

Icons

--icon-sm 14 · --icon-md 16, one size per context

Why. Every parallel control is a place where a hover, a focus ring or a size drifts. Collapsing them is invisible to users when done well, and makes every later polish land everywhere at once.

Seen in. Linear's 2026 refresh rebuilt its controls on one primitive set.
